# src/data

第一段階メイン基板ログシミュレーター向けの実行用データです。

- `symbols.json`: 図柄ID、表示名、図柄分類。
- `reels.json`: 3リール各21コマの配列。`BELL` と `REPLAY` は全リールで最大間隔5コマ。
- `lines.json`: 有効ライン定義。第一段階は上段、中段、下段、右下がり、右上がりの5ライン。
- `roles.json`: 入賞役、払出、再遊技、レア役取りこぼしタグ、ボーナス図柄、リーチ目タグ。
- `bonus-spec.json`: BIG/REGの入賞図柄、2枚掛け14枚払出、終了ゲーム数、総払出、純増。
- `settings.json`: 基本ゲーム値、デフォルト設定、設定1-6と参照テーブルID。
- `tables.json`: 通常時、ボーナス持越し中、BIG中、REG中の抽選テーブル。
- `stop-control.json`: 最大滑り、停止候補順、引き込み優先度、成立時の引き込み対象、未成立役禁止ルール。
- `reach-patterns.json`: ボーナス持越し中に付与できるリーチ目候補。リーチ目は入賞役ではなく払出0。

不変条件:

- JSONはコメントなしの厳密なJSONとしてパースできること。
- `reels.json` は `left`、`center`、`right` がそれぞれ21コマであること。
- 通常時は3枚掛け、ボーナス中は2枚掛けであること。
- 上段、中段、下段、右下がり、右上がりの5ラインを有効ラインとして扱うこと。
- `tables.json` の各テーブルは `entries[].weight` の合計が `denominator` と一致すること。
- `bonus-flagged-*` テーブルに新規 `BIG` / `REG` は含めないこと。
- `BIG` は21G、総払出294、純増252、`REG` は8G、総払出112、純増96で終了すること。
