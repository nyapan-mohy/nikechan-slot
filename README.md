# Nikechan Slot

HTML + Canvas ベースのスマートスロットエミュレーター開発プロジェクトです。

初期版は、液晶付きの AType 告知機とします。ゲーム性はいわゆるジャグラー風のシンプルな完全告知・ボーナス主体の設計とし、既存メーカーや既存機種の商標、図柄、音源、意匠は使用しません。液晶演出は初期版では作り込まず、ボーナス成立時に `BONUS` と表示する最小仕様にします。

現時点の資料は、検定通過を保証する完成資料ではありません。法令、警察庁の解釈基準、指定試験機関の公開情報をもとに、検定通過に必要な仕様・証跡・検証レポートを段階的に作るための計画資料です。

このリポジトリでは、主に以下の成果物を管理します。

- 日本のスマートスロットにおける検定・型式試験を意識した設計資料一式
- 仕様書に準拠して動作するブラウザ上のスマートスロットエミュレーター
- 告知ランプ、リール図柄、液晶演出、SE/BGM などの必要素材リスト
- 筐体案を踏まえたデザイン方針
- 規制・型式試験の参照情報と予備適合性レビュー
