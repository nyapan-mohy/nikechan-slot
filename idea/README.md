# 筐体デザイン案

このディレクトリは、スマートスロット筐体の方向性を検討するための参考画像置き場です。

ここに置いた画像は、実装素材として直接組み込む前提ではなく、デザイン検討用のリファレンスとして扱います。実装時には、既存メーカー、既存機種、既存キャラクター、既存図柄、既存音源、既存筐体意匠のコピーにならないよう、個別パーツをオリジナル素材として作り直します。

## 画像一覧

| ファイル | 方向性 | 使えそうな要素 | 注意点 |
| --- | --- | --- | --- |
| `img/600404b7-5ecb-4570-a5c2-1f7c3587a6a0.png` | 黒ベース、ライブ会場風、ネオン強め | 中央告知部、下パネル、紫/ピンクの発光感 | 情報量が多いため、Aタイプ初期版では演出を整理する |
| `img/aeb3ef08-ebb7-4ec8-834f-fe1ce862779f.png` | 白筐体、上部大型液晶、明るいスマスロ風 | 液晶の見やすさ、ボタン配置、清潔感 | 告知ランプの主役感を別途強める必要あり |
| `img/9370b4e6-e796-43b2-ac0a-3c11bf9f0e68.png` | 金装飾、豪華演出、発光パネル多め | 側面ライト、上部ロゴ、ボーナス画面の華やかさ | Aタイプとしては派手寄りなので、通常時は抑える |

## 現時点の採用方針

- 初期版は `aeb3ef08-ebb7-4ec8-834f-fe1ce862779f.png` のような白筐体・大型液晶構成をベース候補にする。
- 告知ランプやボーナス告知の存在感は `600404b7-5ecb-4570-a5c2-1f7c3587a6a0.png` の中央発光表現を参考にする。
- 高級感や発光パネルは `9370b4e6-e796-43b2-ac0a-3c11bf9f0e68.png` を参考にするが、初期実装では過度に装飾しない。
- 画面設計では、液晶、リール、告知ランプ、クレジット/払出、BET/レバー/STOPボタンの優先順位を崩さない。

## 実装時に分解して作る素材

- 筐体ベース
- 上部液晶
- リール窓
- 告知ランプ
- 1BET/2BET/3BET 表示
- WAIT 表示
- CREDIT/PAYOUT 表示
- MAX BET ボタン
- START/レバー相当ボタン
- STOP ボタン 3個
- 下部パネル
- 側面LED
- ボーナス告知用の液晶背景
