# ボーナス状態遷移・リール制御仕様

## 目的

この資料は、AType 告知機として必要なボーナス状態遷移とリール停止制御の基本方針を定義する。

特に以下を明確にする。

- ボーナス内部成立とボーナス図柄入賞を分ける
- ボーナス成立だけでボーナス役が表示、入賞、開始された扱いにしない
- ボーナス状態は規定枚数到達後に終了演出を経て通常時へ戻る
- 未成立の小役、リプレイ、ボーナス図柄が有効ラインに揃わないようにする
- ボーナス成立状態では目押しが必要で、失敗時はボーナス入賞ではなくリーチ目などの停止形として扱う

この資料では、ユーザー要件の「ボーナス図柄成立」を、リール停止結果としてボーナス図柄が有効ラインに揃う「ボーナス図柄入賞」として扱う。

## ボーナス状態遷移

初期版では、以下の状態を必須とする。

```text
normal
  -> bonusFlagged
  -> bonusSymbolEntered
  -> bonusActive
  -> bonusEnding
  -> normal
```

状態の意味:

- `normal`: 通常時。通常抽選を行う。
- `bonusFlagged`: ボーナス内部成立状態。BIG または REG の内部フラグを保持するが、まだボーナスは開始していない。
- `bonusSymbolEntered`: ボーナス図柄が有効ラインに揃ったゲームの結果処理状態。
- `bonusActive`: BIG または REG の消化中。種別は `bonusType: "BIG" | "REG"` で表す。
- `bonusEnding`: 規定枚数到達後の終了演出、終了音、結果表示を行う状態。

状態IDは `normal`、`bonusFlagged`、`bonusSymbolEntered`、`bonusActive`、`bonusEnding`、`error` に統一する。BIG/REG の違いは状態IDを分けず、`bonusType` で保持する。

重要ルール:

- BIG/REG に内部当選しても、即座に `bonusActive` へ移行しない。
- BIG/REG に内部当選しても、リール上にボーナス図柄を自動で揃えない。
- BIG/REG に内部当選しても、入賞結果としての役表示や払出処理を先に出さない。
- 告知ランプや液晶 `BONUS` は、ボーナス内部成立を知らせる演出であり、ボーナス入賞そのものではない。
- `bonusActive` へ移行するのは、ボーナス成立状態中に有効ラインへ該当ボーナス図柄が揃った後とする。
- `bonusActive` は規定枚数、規定払出、または仕様で定める終了条件に到達したら `bonusEnding` へ移行する。
- `bonusEnding` の終了後、通常時へ戻る。

## ボーナス成立状態

`bonusFlagged` では、成立した BIG または REG の内部フラグを持ち越す。

持越し対象:

- BIG
- REG

持越し中の扱い:

- 通常ゲームとして BET、START、STOP を行う。
- 特別テーブルを使い、新規BIG/REGは一切抽選しない。
- 小役、リプレイは抽選する。
- ボーナス図柄を狙って停止できた場合のみ、ボーナス図柄入賞へ進む。
- 目押し範囲外で停止した場合は、ボーナス図柄を揃えない。
- 目押し失敗時は、仕様で定義したリーチ目、チャンス目、通常ハズレ目のいずれかを停止結果タグとして記録できる。
- リーチ目は演出・表示上の停止形分類であり、未成立小役の入賞やボーナス開始を意味しない。

## 抽選結果の構造

1ゲームの抽選結果は、ボーナスと小役系を分けて保持する。

```json
{
  "bonus": "BIG",
  "smallRole": "BELL",
  "replay": null
}
```

ルール:

- ボーナスと小役の同時成立はありうる。
- 初期版ではボーナスとリプレイの同時成立は採用しない。
- 小役同士の同時成立は行わない。
- 小役とリプレイの同時成立は行わない。
- 1ゲームで入賞可能な小役系は最大1種類とする。
- `bonusFlagged` 中に新たな BIG/REG を重複成立させない。

## 小役分類

小役は、停止制御上の扱いによって通常小役とレア小役に分ける。

通常小役:

- 目押ししなくても揃う設計にする。
- 成立時は最大滑りコマ数の範囲で入賞図柄を引き込む。
- リール配列上、どの押下位置からでも入賞可能になるよう図柄配置を調整する。
- 初期版の代表例: ベル。
- リプレイは小役とは別カテゴリとして扱う。

レア小役:

- 目押し必須の小役として扱う。
- 成立していても、押下位置が入賞可能範囲外なら揃えない。
- 目押し失敗時は取りこぼし停止形、チャンス目、またはリーチ目系の停止結果タグを付ける。
- 取りこぼし時は、成立役ログにはレア小役成立を残すが、入賞役と払出は停止結果に従う。
- 代表例: チェリー、スイカ、特殊役など。初期版で採用する具体役は `roles.json` で定義する。

`roles.json` では、各小役に以下の属性を持たせる。

```json
{
  "id": "RARE_CHERRY",
  "type": "smallRole",
  "rarity": "rare",
  "requiresAim": true,
  "payout": 2,
  "cornerPayout": 4,
  "winningPattern": ["CHERRY", "ANY", "ANY"],
  "missResultTags": ["rareMiss", "chancePattern"]
}
```

通常小役の例:

```json
{
  "id": "BELL",
  "type": "smallRole",
  "rarity": "normal",
  "requiresAim": false,
  "payout": 5,
  "winningPattern": ["BELL", "BELL", "BELL"]
}
```

スイカはレア小役として扱い、初期払出は15枚とする。スイカ確率は機械割調整用に使ってよく、極端に重い確率になっても許容する。REPLAYは払出0枚で、次ゲームを同じ掛け枚数で再遊技にする。ボーナス図柄入賞とリーチ目には払出を付けない。

初期実装では、抽選結果を以下のように正規化する。

```json
{
  "bonusCandidate": "BIG",
  "carriedBonus": null,
  "activeBonus": "BIG",
  "smallRole": "BELL",
  "smallRoleRarity": "normal",
  "requiresAim": false,
  "isReplay": false
}
```

意味:

- `bonusCandidate`: このゲームで新たに抽選されたボーナス。
- `carriedBonus`: 前ゲーム以前から持ち越しているボーナス。
- `activeBonus`: 停止制御上、入賞可能なボーナス。`bonusCandidate` または `carriedBonus`。
- `smallRole`: このゲームで成立した小役。
- `smallRoleRarity`: 成立小役が通常小役かレア小役かを示す。
- `requiresAim`: 成立小役が目押し必須かを示す。
- `isReplay`: リプレイ成立。

## 停止制御の基本方針

停止制御は、押下位置から滑り範囲内の候補を評価して、停止位置を決める。

入力:

- リール配列
- 押下時のリール位置
- 最大滑りコマ数
- 成立小役
- リプレイ成立有無
- 持越し中のボーナス
- このゲームで成立したボーナス
- 有効ライン定義
- 停止済みリールの位置

出力:

- 実停止位置
- 表示窓に見える図柄
- 有効ライン上の入賞結果
- 停止結果タグ
- 滑りコマ数

候補評価:

1. 押下位置から最大滑りコマ数までの停止候補を作る。
2. 各候補について、全リール停止後に成立していない役が揃う可能性を評価する。
3. 未成立の小役、リプレイ、ボーナスが有効ラインに揃う候補を除外する。
4. ボーナスが成立または持越し中で、押下位置がボーナス図柄入賞可能範囲にある場合は、ボーナス図柄入賞候補を最優先にする。
5. ボーナス図柄を引き込めない場合に、成立しているリプレイを引き込める候補を優先する。
6. ボーナス図柄を引き込めない場合に、成立小役が通常小役なら最大滑りコマ数の範囲で入賞図柄を引き込む。
7. ボーナス図柄を引き込めない場合に、成立小役がレア小役なら押下位置が入賞可能範囲内のときだけ入賞候補を許可する。
8. レア小役の目押し失敗時は、成立していない役を揃えない停止形から選び、取りこぼしタグを付与する。
9. ボーナス図柄入賞、小役入賞、リプレイ入賞のいずれも不可能な場合は、未成立役を揃えない停止形から選ぶ。
10. 必要に応じて、リーチ目タグを付与する。

禁止事項:

- 成立していない小役を有効ラインに揃える。
- 成立していないリプレイを有効ラインに揃える。
- ボーナス未成立時にボーナス図柄を有効ラインに揃える。
- ボーナス成立だけで、目押しなしに必ずボーナス図柄を揃える。
- レア小役成立時に、目押し範囲外でも必ずレア小役を揃える。
- レア小役取りこぼし時に、未成立の別小役を代わりに揃える。
- 小役同士を同時成立させる。

## 優先順位

初期実装では、停止制御の優先順位を以下のように置く。

1. 未成立役を揃えない
2. ボーナス成立または持越し中で目押し範囲内の場合はボーナス図柄入賞を許可する
3. ボーナス図柄を引き込めない場合、リプレイ成立時はリプレイを入賞させる
4. ボーナス図柄を引き込めない場合、通常小役成立時は成立小役を入賞させる
5. ボーナス図柄を引き込めない場合、レア小役成立時は目押し範囲内の場合だけ成立小役を入賞させる
6. ボーナス図柄もレア小役も引き込めない場合は、取りこぼし停止形を出す
7. ボーナス成立状態でボーナス図柄入賞できず、成立小役やリプレイも入賞できない場合は、リーチ目または非入賞停止形を出す
8. ハズレ時は、いずれの入賞役も揃えない

小役またはリプレイとボーナスが同時成立しているゲームでは、ボーナス図柄入賞を最優先にする。押下位置がボーナス図柄を引き込めない位置だった場合のみ、成立している小役またはリプレイの入賞を許可する。たとえばチェリーとボーナスが同時成立し、7図柄の下のコマにチェリーがある場合でも、7図柄が引き込み範囲内なら7を下段に引き込む。

ボーナス成立ゲーム以降の `bonusFlagged` では、特別テーブルを使い、新規ボーナス抽選は一切行わない。ただし小役とリプレイの抽選は継続する。ボーナス待機状態では、ボーナス図柄を揃えられる押下位置ならボーナス図柄入賞、揃えられない押下位置で小役が成立していれば小役入賞とする。小役もリプレイも成立しておらず、ボーナス図柄を2リール目または3リール目に引き込めない停止操作だった場合は、リーチ目になるように停止制御する。

## リーチ目

リーチ目は、ボーナス内部成立状態で出現しうる停止結果タグとして扱う。

ルール:

- リーチ目は入賞役ではない。
- リーチ目そのものに払出はない。
- リーチ目はボーナス開始条件ではない。
- リーチ目表示後も、ボーナス図柄を有効ラインに揃えるまでは `bonusFlagged` を維持する。
- リーチ目の停止形は、リール配列確定後に `reach-patterns.json` などで定義する。

## 必要データ

```text
src/data/
  symbols.json
  reels.json
  roles.json
  lines.json
  stop-control.json
  reach-patterns.json
  bonus-spec.json
```

`stop-control.json` に含める項目:

- 最大滑りコマ数
- 役別の引き込み優先度
- 通常小役の引き込み対象
- レア小役の目押し許容範囲
- レア小役取りこぼし時の停止結果タグ
- 未成立役の禁止ライン
- ボーナス入賞可能条件
- リーチ目候補

`bonus-spec.json` に含める項目:

- BIG 入賞図柄
- REG 入賞図柄
- BIG 終了条件
- REG 終了条件
- 規定枚数
- 終了演出の状態名

## コアモジュール

```text
src/core/
  lottery.ts
  role-result.ts
  game-state.ts
  reel.ts
  stop-control.ts
  line-evaluator.ts
  bonus-state.ts
  payout.ts
```

責務:

- `lottery.ts`: ボーナス、小役、リプレイの抽選結果を作る。
- `role-result.ts`: 1ゲームの成立役を正規化する。
- `stop-control.ts`: 押下位置と成立役から停止位置を決める。
- `line-evaluator.ts`: 停止結果から入賞役を判定する。
- `bonus-state.ts`: `normal`、`bonusFlagged`、`bonusSymbolEntered`、`bonusActive`、`bonusEnding` を管理する。
- `payout.ts`: 入賞役と状態に応じて払出を計算する。

## テスト観点

- BIG成立ゲームで、ボーナス図柄を狙えない位置ならBIG図柄が揃わない。
- BIG成立ゲームで、ボーナス図柄を狙える位置ならBIG図柄入賞へ進める。
- REG成立ゲームで、ボーナス図柄を狙えない位置ならREG図柄が揃わない。
- REG成立ゲームで、ボーナス図柄を狙える位置ならREG図柄入賞へ進める。
- ボーナス成立だけでは `bonusActive` に移行しない。
- ボーナス図柄入賞後に `bonusActive` へ移行する。
- 規定枚数到達後に `bonusEnding` へ移行する。
- `bonusEnding` 完了後に `normal` へ戻る。
- 小役未成立時に小役が揃わない。
- 通常小役成立時は、押下位置にかかわらず最大滑りコマ数の範囲で小役が揃う。
- レア小役成立時は、目押し範囲内ならレア小役が揃う。
- レア小役成立時は、目押し範囲外ならレア小役が揃わず、取りこぼしタグが残る。
- レア小役取りこぼし時に、未成立の別小役が揃わない。
- リプレイ未成立時にリプレイが揃わない。
- ボーナス未成立時にボーナス図柄が揃わない。
- 小役とボーナスが同時成立した場合、ボーナス図柄の引き込みを優先し、引き込めない場合のみ成立小役を入賞させる。
- 小役同士が同時成立しない。
- ボーナス成立状態で目押し失敗した場合、ボーナス入賞せず、必要に応じてリーチ目タグを出す。
