# 初期AType仕様

## 目的

初期バージョンでは、液晶付きの AType 告知機として、最小限の遊技体験と検証可能なコアロジックを先に作る。

方向性は、いわゆるジャグラー風のシンプルな完全告知系 AType とする。既存機種の固有名称、商標、図柄、告知ランプ、音源、筐体意匠は使用しない。

## 初期バージョンの範囲

- 3リール
- 3STOPボタン
- MAX BET
- レバー相当の START 操作
- CREDIT 表示
- PAYOUT 表示
- 設定1から設定6
- 第一段階メイン基板ログシミュレーター
- エミュレーター専用オートモード
- エミュレーター専用リールWaitなし
- エミュレーター専用強制BIG/REG成立ボタン
- 通常時
- ボーナス成立状態
- ボーナス図柄入賞
- BIG
- REG
- 規定枚数到達後のボーナス終了演出
- 告知ランプまたは告知エリア
- 液晶の `BONUS` 表示
- データ表示端末

## 液晶仕様

初期バージョンでは、液晶演出は作り込まない。

- 通常時: 静止背景または簡易待機表示
- ボーナス成立時: 液晶に `BONUS` と表示
- BIG中: `BIG BONUS` または `BIG`
- REG中: `REG BONUS` または `REG`
- エラー時: エラー内容を文字で表示

表示文字は `BONUS` に統一する。

初期バージョンでは、以下を行わない。

- 連続演出
- 前兆演出
- 上位状態示唆
- 複数回抽せんしたように見える演出
- 出玉性能を期待させる数値表示
- 既存機種に類似しすぎる告知音、ランプ形状、図柄、液晶演出

## 告知仕様

ボーナス成立時は、告知ランプまたは告知エリアの点灯と、液晶の `BONUS` 表示でプレイヤーに知らせる。

初期バージョンでは、告知タイミングは以下のどちらかに固定する。

- 後告知: 第3停止後に告知する
- 先告知: レバーON時に告知する

どちらを採用するかは、ゲーム仕様作成時に決定する。ランダムに見せる場合でも、仕様書上は明確な抽選・条件として定義する。

## ボーナス仕様

初期バージョンでは、ボーナスは BIG と REG の2種類を基本とする。

- BIG: 払出期待値が大きいボーナス
- REG: 払出期待値が小さいボーナス

特殊ボーナス、上位ボーナス、AT、ART、CZ、疑似ボーナスは初期対象外とする。

ボーナスは以下の順に状態遷移する。

```text
通常時
  -> ボーナス成立状態
  -> ボーナス図柄入賞
  -> ボーナス状態
  -> 規定枚数到達後終了演出
  -> 通常時
```

ボーナス成立状態は内部フラグの持越し状態であり、ボーナス成立だけでボーナス図柄が揃った扱いにはしない。液晶の `BONUS` 表示と告知ランプは、ボーナス内部成立を知らせる演出であり、ボーナス図柄入賞やボーナス状態開始そのものではない。

## 抽選・リール制御仕様

ボーナスと小役は同時成立しうるが、小役同士の同時成立は行わない。

- 設定1から設定6までを持つ。
- BIG/REG成立確率は設定別に差をつける。
- 小役の成立確率はベルのみ設定別に差をつける。
- チェリー、スイカ、ボーナス同時成立チェリーは全設定共通にする。
- リプレイは小役とは別カテゴリとし、50枚あたり約40Gのベース調整のため設定別に差をつける。
- 抽選は現在設定に対応する抽選テーブルを参照する。
- 1ゲームで成立する小役系は最大1種類とする。
- 小役は通常小役とレア小役に分類する。
- 通常小役は目押ししなくても揃うように、停止制御で最大滑りコマ数の範囲内へ引き込む。
- レア小役は目押し必須とし、押下位置が入賞可能範囲外の場合は取りこぼし停止形にする。
- レア小役取りこぼし時は、成立ログにはレア小役成立を残すが、入賞役と払出は停止結果に従う。
- 成立していない小役、リプレイ、ボーナス図柄を有効ラインに揃えない。
- ボーナス未成立時にボーナス図柄を揃えない。
- ボーナス成立状態では、目押し範囲内でのみボーナス図柄入賞を許可する。
- ボーナス成立状態で目押しに失敗した場合は、ボーナス図柄入賞ではなくリーチ目または非入賞停止形として扱う。
- 小役とボーナスが同時成立した場合は、ボーナス図柄の引き込みを優先する。
- ボーナス図柄を引き込めない位置で停止操作された場合のみ、成立小役の入賞を許可する。
- ボーナス成立状態では新規ボーナス抽選を行わず、小役とリプレイだけを抽選する。
- ボーナス成立状態で小役もリプレイも成立せず、ボーナス図柄も引き込めない場合は、リーチ目または非入賞停止形にする。
- 停止制御では、押下位置から滑り範囲内の停止候補を評価する。

詳細は `docs/spec/bonus-and-reel-control-spec.md` に定義する。

設定と抽選テーブルの詳細は `docs/spec/settings-and-lottery-tables-spec.md` に定義する。

## 検定観点の注意

- 液晶の `BONUS` 表示は、リール停止結果や役判定を阻害しない。
- 液晶演出は、1回の遊技で複数回抽せんしたように見せない。
- 告知表示は、出玉性能を誤認させる数値や表現を含めない。
- STOPボタンと回胴の対応は左・中・右で固定する。
- ボーナス成立だけで役表示、入賞表示、ボーナス開始表示を出さない。
- 停止制御は未成立役を揃えないことを最優先にする。
- デバッグ用のオートプレイ、設定変更、ログ出力は実機仕様から分離する。
- オートモード、リールWaitなし、強制BIG/REG成立ボタンはエミュレーター専用機能として扱い、通常抽選・停止制御・入賞判定・払出の仕様と分離する。

## エミュレーター専用展示・デバッグ機能

初期エミュレーターでは、展示と検証をしやすくするために以下を実装対象に含める。

- オートモード: BET、START、左/中/右STOPを自動実行する。
- リールWaitなし: 回転待ち、STOP間隔、払出表示待ちなどを短縮し、遊技結果を変えずにテンポだけを上げる。
- 強制BIG成立ボタン: 次ゲームの成立役をBIGとして予約する。
- 強制REG成立ボタン: 次ゲームの成立役をREGとして予約する。

これらの機能は、実機仕様ではなくエミュレーター専用アダプタとして実装する。強制BIG/REGを使ったゲームはログ上で通常抽選と区別し、通常シミュレーションの出現率や出玉率集計から除外できるようにする。

詳細は `docs/spec/emulator-demo-control-adapters.md` に定義する。

## データ表示端末

初期エミュレーターでは、遊技機本体とは別機能としてデータ表示端末を実装対象に含める。

遊技機能は、現在状態、ゲーム開始、抽選結果、停止結果、入賞判定、払出、ボーナス開始、ボーナス終了などのイベントを出力する。データ表示端末はその出力を購読し、以下を表示する。

- 現在の状態表示
- 動作回転数
- ボーナス間ゲーム数表示
- 現在設定
- BIG回数
- REG回数
- 大当たり確率
- 小役成立数
- 小役成立確率
- スランプグラフ

動作回転数はボーナスゲームを含めない。データ表示端末は遊技状態を変更できない読み取り専用機能とする。

詳細は `docs/spec/data-display-terminal-spec.md` に定義する。

## 第一段階メイン基板ログシミュレーター

第一段階では、筐体Canvasや演出より先に、メイン基板相当の処理ログをブラウザ上のターミナル風画面で確認できるようにする。

最低限の機能:

- 1ゲーム実行
- Bonusまで実行
- 現在状態の表示
- 現在設定の表示
- 乱数シードの表示
- BET、START、抽選、停止、入賞、払出、状態遷移ログの表示
- ボーナス内部成立時の停止

`Bonusまで実行` は、初期版ではボーナス内部成立まで自動実行する。ボーナス図柄入賞またはボーナス状態開始まで進めるモードは後続拡張とする。

最終的には、HTML + Canvas の筐体表示、内部状態、筐体動作、シミュレーション用機能、データ表示端末、スランプグラフ、メイン基板ログを1つのブラウザUI内に統合する。

詳細は `docs/spec/main-board-log-simulator-spec.md` に定義する。

## 詳細仕様と今後の精緻化項目

第一段階ログシミュレーターで必要なリール図柄構成、リール配列、有効ライン、小役構成、BIG/REG入賞図柄、払出、ボーナス純増、設定別抽選テーブル、設定別機械割は `docs/spec/first-stage-minimum-data-spec.md` に定義済みとする。

今後の精緻化対象:

- 告知タイミング
- 角チェリー2ライン判定
- スイカ取りこぼし停止形
- リーチ目停止形の具体パターン
- ボーナス中の消化ログと終了演出
- スマスロ用クレジット管理仕様
- データ表示端末の公開UI配置
