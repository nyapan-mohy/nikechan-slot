# スマートスロットエミュレーター フェーズ計画

## 目的

このプロジェクトでは、HTML + Canvas を使った仕様準拠型のスマートスロットエミュレーターを開発しつつ、日本のスマートスロットにおける検定・型式試験を意識した設計資料を整理します。

初期版の機種タイプは、液晶付きの Aタイプ告知機とします。ゲーム性はシンプルな完全告知・ボーナス主体の設計を想定し、既存メーカーや既存機種の商標、図柄、音源、筐体意匠は使用しません。参考にするのは「短時間で遊技状態が理解できる告知機」という体験構造であり、固有のデザインや素材はすべてオリジナルで作成します。

現時点の資料は、検定通過を保証する完成資料ではありません。実際の型式試験では、設計書、仕様書、実機、主制御ROM、構造図、回路図、取扱説明書、写真、試験結果、仕様書と実機の対比照合が必要になります。本プロジェクトでは、検定通過に必要な証跡を段階的に作る前提で進めます。

重要な前提として、実際の日本の回胴式遊技機に対する型式試験は、ブラウザアプリ単体ではなく、筐体、主制御基板、副制御基板、電源、クレジット管理、表示、音響、ROM、プログラム、構造などを含む「遊技機の型式」に対して行われます。そのため、本プロジェクトでは以下を明確に分離します。

- 検定・型式試験を意識した設計資料
- エミュレーターとして実装・検証できる仕様
- 実機化する際に別途必要になるハードウェア・製造・申請関連の不足項目

## 素材要件

目的: Aタイプ告知機として必要な画像、音、UI素材を事前に洗い出し、実装中に素材不足で止まらない状態にします。

重要方針:

- 既存メーカー、既存機種、既存キャラクター、既存告知ランプ、既存図柄、既存音源のコピーは使用しない
- `idea/img/` の筐体案はデザイン検討用リファレンスとして扱い、実装素材は個別に作り直す
- 初期版は仮素材で実装し、仕様が固まった段階で本制作素材に差し替える
- 素材ごとに、用途、形式、サイズ、ループ可否、ライセンス、差し替え期限を管理する
- Canvas 上で拡大縮小しても破綻しないよう、画像は高解像度またはベクター元データを保持する

必須画像素材:

- リール図柄: 赤7、青7、BAR、ベル、チェリー、リプレイ、ブランク、機種固有シンボル
- 図柄の元データ: 透過 PNG または SVG、Canvas 表示用には PNG 書き出し
- リール帯: 3リール分の縦長ストリップ画像、または図柄単位で組み立てるためのパーツ
- 告知ランプ: 消灯、待機、点灯、点滅、プレミア点灯の各状態
- 筐体パネル: 上部パネル、リール窓、下部パネル、ボタン周辺、クレジット表示周辺
- 操作ボタン: MAX BET、レバー、停止ボタン左・中・右、精算、設定/デバッグ用ボタン
- 液晶背景: 通常時、ボーナス確定時、ボーナス中、エラー時、デモ時
- 液晶演出パーツ: 告知時のフラッシュ、文字演出、簡易キャラクターまたは抽象モチーフ
- UIアイコン: 音量、ミュート、オートプレイ、リセット、ログ出力、設定変更、情報表示

必須サウンド素材:

- レバーON音
- 各停止ボタン音
- リール始動音
- リール停止音
- ベット音
- クレジット投入/加算音
- 払出音
- 告知ランプ点灯音
- ボーナス確定ジングル
- BIG開始ジングル
- REG開始ジングル
- ボーナス中BGM
- ボーナス終了音
- エラー音
- メニュー操作音

BGM要件:

- 通常時は原則BGMなし、または極小の環境音に留める
- ボーナス中BGMは BIG 用と REG 用を分ける
- BGMはループ可能な構造にする
- ブラウザの自動再生制限を前提に、最初のユーザー操作後に音声を有効化する

液晶演出要件:

- Aタイプらしく、通常時は情報量を抑える
- 告知時はランプ点灯を主役にし、液晶は補助演出として扱う
- 派手な連続演出や上位状態示唆演出は初期版の対象外
- プレミア告知は将来拡張として素材枠だけ確保する

素材管理ドキュメント:

- `docs/assets/asset-list.md`: 素材一覧、用途、優先度、形式、担当、状態
- `docs/assets/audio-spec.md`: SE/BGM の長さ、音量、ループ、再生タイミング
- `docs/assets/image-spec.md`: 画像サイズ、透過、スケール、命名規則
- `docs/assets/copyright-policy.md`: 権利確認、禁止事項、外部素材の利用条件

## 筐体画像を踏まえた設計方針

目的: `idea/img/` に配置された筐体案を、実装可能かつ検定観点で問題が出にくいデザイン方針へ落とし込みます。

採用方針:

- 白筐体案の整理されたレイアウトを初期ベース候補にする
- 黒ベース案の中央告知エリアとネオン感を、告知時の強調表現として取り入れる
- 金装飾案の豪華さは、ボーナス中や上位演出の参考に留める
- 通常時は図柄識別と操作性を最優先にし、装飾発光を抑える
- 液晶は大きく配置するが、役判定や回胴停止結果を誤認させない補助演出に限定する

検定観点の制約:

- リール窓周辺の発光や液晶演出で、回胴上の図柄識別を妨げない
- 液晶上の演出図柄が、回胴の図柄組合せや内部抽せん回数を誤認させない
- 告知ランプはボーナス当選を分かりやすく示すが、出玉性能を誤認させる表示は行わない
- STOP ボタンは左・中・右の回胴と一対一で固定する
- デバッグ用オートプレイ、設定変更、ログ出力はエミュレーター専用機能として実機仕様から分離する
