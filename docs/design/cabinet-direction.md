# 筐体デザイン方針

## 前提

`idea/img/` に配置された3案をもとに、初期版のスマートスロット筐体方向性を整理する。

この画像は実装素材ではなく、デザイン検討用のリファレンスとして扱う。実装素材は、権利確認済みのオリジナル素材として個別に制作する。

## 目指す筐体

初期版は、液晶付き Aタイプ告知機として設計する。

- 3リール中心の遊技性
- BIG/REG を主役にしたボーナス主体
- 告知ランプまたは告知エリアで当選を明確に伝える
- 液晶は主役ではなく、告知・ボーナス・デモ・エラーの補助表示に使う
- 操作部は MAX BET、レバー相当、STOP 3個、精算/送信系操作を明確に分ける
- 通常時は情報量を抑え、ボーナス告知時だけ発光・音・液晶演出を強くする

## 画像案から採用する要素

### 黒ベース案

対象: `idea/img/600404b7-5ecb-4570-a5c2-1f7c3587a6a0.png`

採用候補:

- 黒ベースにピンク/紫/青ネオンを重ねる方向性
- 中央告知エリアの強い存在感
- 下パネルのライブ感
- ボーナス時の発光量

注意点:

- 情報量が多く、Aタイプとしては通常時の視認性を損ないやすい
- 初期実装では発光量を抑え、告知時だけ強くする

### 白筐体案

対象: `idea/img/aeb3ef08-ebb7-4ec8-834f-fe1ce862779f.png`

採用候補:

- 白筐体による明るさと現代的なスマスロ感
- 上部大型液晶の見やすさ
- リール、カウンター、操作部の整理された配置
- 左右ランプの分かりやすい発光ライン

注意点:

- 告知ランプの主役感が弱くなりやすい
- 告知専用エリアをリール上またはリール横に明確に設ける

### 金装飾案

対象: `idea/img/9370b4e6-e796-43b2-ac0a-3c11bf9f0e68.png`

採用候補:

- 側面LEDと上部ロゴの華やかさ
- ボーナス画面のインパクト
- 下パネルの高級感

注意点:

- 初期版では豪華装飾を優先しない
- 通常時に過剰な発光をさせず、ボーナス時の差分として扱う

## 初期版レイアウト方針

優先順位:

1. 回胴と図柄の視認性
2. STOP ボタン 3個の一対一対応
3. クレジット、払出、BET 状態の視認性
4. 告知ランプまたは告知エリア
5. 液晶演出
6. 装飾LEDと下パネル

画面構成:

- 上部: 液晶。通常時は静か、ボーナス告知時とボーナス中に演出する。
- 中央: リール窓。図柄識別を最優先にする。
- リール周辺: 告知ランプ、BET 状態、WAIT 表示。
- 下部: CREDIT/PAYOUT、MAX BET、レバー相当、STOP 3個。
- 最下部: 下パネル。機種ロゴとキャラクター表現を配置する。

## 検定観点のデザイン制約

実機化を前提にする場合、筐体デザインは以下を守る必要がある。

- 回胴上の図柄識別を妨げない
- 液晶演出が、回胴の停止結果や内部抽せん回数を誤認させない
- STOP ボタンと停止する回胴の対応を変更しない
- 設定変更操作を遊技者が操作できる構造にしない
- 出玉性能を誤認させる表示をしない
- スマスロの遊技メダル数表示や外部送信操作は、規則上の要件と矛盾しないよう別途仕様化する
