# 音素材仕様

## 基本方針

- 初期版は AType 告知機として、通常時は静かに、告知時とボーナス中に音でメリハリを出す。
- 既存機種の効果音、告知音、BGM は使用しない。
- SE は `wav` をマスター、ブラウザ配信用に `ogg` または `mp3` を用意する。
- BGM はループ前提で制作し、ループ開始・終了位置を記録する。

## 音量設計

- 告知音を基準音量にする。
- レバー、停止、ベットなどの操作音は告知音より小さくする。
- ボーナスBGMは操作音や払出音を潰さない音量にする。
- エラー音は認知できる音量にするが、長時間鳴り続けても不快になりすぎないようにする。

## 再生タイミング

| イベント | 再生素材 | 備考 |
| --- | --- | --- |
| BET | `se-bet` | クレジット不足時は別音を検討 |
| レバーON | `se-lever`, `se-reel-start` | リール始動と同期 |
| 各停止 | `se-stop-left` など | 共通SEでも可 |
| 入賞払出 | `se-payout` | 払出枚数に応じた反復を検討 |
| ボーナス告知 | `se-notice` | 告知ランプ点灯と同期 |
| BIG開始 | `se-big-start`, `bgm-big` | ジングル後にBGM |
| REG開始 | `se-reg-start`, `bgm-reg` | ジングル後にBGM |
| ボーナス終了 | `se-bonus-end` | 結果表示と同期 |
| エラー | `se-error` | エラー解除まで制御 |
