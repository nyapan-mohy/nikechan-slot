# 素材一覧

## 管理方針

このファイルでは、スマートスロットエミュレーターで使用する画像、SE、BGM、アイコン、演出素材を管理します。

既存メーカー、既存機種、既存キャラクター、既存図柄、既存音源、既存告知ランプのコピーは使用しません。外部素材を使用する場合は、商用利用可否、改変可否、クレジット表記要否、再配布可否を確認して記録します。

筐体デザイン案は `idea/img/` に配置します。これらはリファレンス扱いとし、実装素材として直接使用する場合は、権利・利用条件・生成元を確認してからこの台帳へ正式素材として登録します。

ステータス:

- 未着手
- 仮素材
- 制作中
- 完了
- 差し替え必要

優先度:

- P0: 最小プレイアブル版に必須
- P1: 初期完成版に必要
- P2: 演出強化・将来拡張

## 実装メモ

- ブラウザの自動再生制限により、音声は最初のユーザー操作後に有効化する。
- P0 素材は仮素材でよいが、ファイル名と参照IDは本制作時も維持する。
- Canvas描画では、元素材を直接拡大するのではなく、表示サイズに合わせた読み込み・キャッシュ方針を決める。
- 音量バランスは素材単体ではなく、実機UI上の再生タイミングで確認する。
