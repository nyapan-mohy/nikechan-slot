# 素材の権利方針

## 禁止事項

- 既存メーカー名、既存機種名、既存キャラクター、既存ロゴの無断使用
- 既存告知ランプ、既存図柄、既存筐体パネルのコピー
- 既存機種のSE、BGM、ジングルのコピーまたは類似しすぎる再制作
- 利用条件が不明な画像・音源の組み込み

## 外部素材を使う場合の確認項目

- 商用利用できるか
- 改変できるか
- クレジット表記が必要か
- アプリ内配布・GitHubでの再配布が許可されるか
- AI生成素材の場合、利用規約上の制限がないか

## 記録方法

外部素材を採用する場合は、`docs/assets/asset-list.md` の備考欄に以下を記録します。

- 入手元URL
- ライセンス名
- 利用条件
- クレジット表記要否
- 確認日
